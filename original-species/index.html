Play on Your Phone

100% Mobile Optimized!

You can save this single file onto your Android or iOS device and play offline anytime without installing an app store app.

Android Installation Guide

  1. Save or export this HTML file to your phone's storage (e.g., Downloads folder).
  2. Open your phone's file manager app and locate the file.
  3. Tap the HTML file and choose to open it with Google Chrome, Samsung Internet, or any web browser.
  4. For quick access, tap the browser menu (3 dots) and select "Add to Home Screen".

iPhone & iPad (iOS) Guide

  1. Send this HTML file to your iPhone via iCloud Drive, AirDrop, or email.
  2. Open the file in the Files app on iOS.
  3. Tap the Share icon at the bottom left.
  4. Scroll down and select "Save to Files" or open directly in Safari.
  5. In Safari, tap the Share button and select "Add to Home Screen" to play like a native app!
